# Open-source engineering platform benchmark

Research date: 2026-10-30. The items below are **external references**, not imported assets.

| Reference | Useful idea | Original AI Engineer implementation |
|---|---|---|
| https://github.com/github/awesome-copilot | searchable agent/skill discovery, contributions | versioned local JSON catalog, search CLI and provenance |
| https://github.com/microsoft/skills | curated language/technology packs | modular packs and user-selected project installation |
| https://github.com/All-Hands-AI/OpenHands | sandboxed coding task execution | future runtime adapter with least-privilege tool scopes |

| https://github.com/microsoft/agent-framework | multi-agent lifecycle and interoperability | runtime-independent orchestration contracts |
| https://github.com/agentsmd/agents.md | repository-specific agent guidance | AGENTS.md with confidentiality and validation guidance |

## Gaps addressed now
- Discoverability: machine-readable scenarios and CLI search.
- User onboarding: start-here guide and project-local installation steps.
- Governance: provenance instructions and validation.
- Coverage: scenarios spanning FinCrime, APIs, data pipelines, releases and incidents.

## Still missing
Production orchestration, runtime connectors, persistent private knowledge graph, scored evaluations, SBOM/license audit, installable signed releases, automated distribution PRs and monitored rollouts. No performance claim is made.
